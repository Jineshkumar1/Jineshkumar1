## 👨‍💻 About Me

I am a Cloud Infrastructure Consultant with a proven track record of delivering solutions across diverse industries such as Energy, Financial Services, Healthcare, and Telecommunications. Performed at various Roles where I help organizations achieve successful IT infrastructure migration, optimization, and modernization by leveraging leading cloud platforms and DevOps practices. My focus is on enabling business transformation through innovative, secure, and scalable cloud solutions.

- 🔭 I specialize in cloud infrastructure automation with tools like Terraform, Ansible, and various CI/CD DevSecOps solutions
- 👷‍♂️ I worked on many cloud migration projects, assisting with re-platforming and refactoring applications on Cloud Platforms.
- 🏆 I hold several industry-standard professional certifications, including **☁️ AZ-400 Azure DevOps Expert**, **☁️ AZ-104 Azure Administrator**, **🏆 Terraform Associate**, and **☁️ AWS Solutions Architect**.
- 👯 I'm looking to collaborate with people working on cloud Infrastructure and DevOps projects focused on automation and infrastructure optimization
- 💬 Ask me about cloud infrastructure, automation, solution architecture, and modern development practices
- ⚡ Fun fact: When I'm not working, I enjoy exploring new technologies, attending meetups, and sharing knowledge with the community.
